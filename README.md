# বাজার দর / BazarDor

BazarDor is a modern, fast, and fully-responsive web application built to help users effortlessly track the daily prices of essential groceries across local markets. It offers an intuitive interface to monitor market trends, compare prices, and seamlessly sign in to customize their experience.

## Technologies Used

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Database**: MongoDB (Local/Atlas)
- **Authentication**: Better Auth
- **Forms & Validation**: React Hook Form, Zod
- **Icons**: Lucide React
- **Notifications**: Sonner

## 5 Key Features

1. **Live Price Ticker**: A continuously scrolling marquee in the navigation bar displaying the latest real-time prices for popular grocery items across the country.
2. **Category & Product Dashboards**: Dedicated dynamic pages to browse products by category (e.g., Rice, Dal, Vegetables) and view detailed historical price comparisons and individual market rates.
3. **Responsive Design System**: A pixel-perfect, mobile-first design leveraging Tailwind CSS to ensure the app looks stunning and functions flawlessly on any device screen size.
4. **Secure User Authentication**: Full user account system supporting email/password registration and social login integrations (Google & GitHub) backed by MongoDB and Better Auth.
5. **Dynamic Profile Management**: Protected routes allowing authenticated users to easily manage their accounts, update their profile information, and stay securely logged in across sessions.
